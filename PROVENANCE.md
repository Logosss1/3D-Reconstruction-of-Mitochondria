# Project Provenance

This repository is the research implementation and experiment record for the
undergraduate capstone thesis **Simplified Convolutional Occupancy Network
Based 3D Reconstruction for Mitochondria** by Yuhao Lu, Wenzhou-Kean
University, supervised by Gao Zhiqiang, April 2026.

The thesis is recorded in the university library. It is not represented here
as a publicly indexed online publication, and this repository does not claim a
thesis DOI or a public publisher landing page.

## What this repository contains

- Original Python and shell code written for the capstone experiments.
- Configuration and environment information used by the experimental runs.
- Generated meshes, figures, logs, and visualizations produced during the
  project.
- Thesis-related images included for research communication and result
  inspection.

## What this repository does not claim

- The MIT license does not grant rights to external datasets, third-party
  packages, or university-owned thesis material.
- Results in this repository are not a guarantee of production-level
  reconstruction quality.
- A checked-in output or checkpoint is not necessarily a complete reproduction
  of every thesis run.
